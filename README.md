# HVAC Operations Dashboard

A responsive HVAC AI CSR operations dashboard prototype built with Next.js, TypeScript, Tailwind CSS, and Lucide icons.

## Scope

- Dashboard overview
- Customers
- Appointments with owner review, technician assignment, and approval workflow
- Service requests
- Call history

This first version uses local mock data only. It does not connect to authentication, a database, LiveKit, Google Calendar, or SMS.

Appointments remain pending approval until an owner approves them. Customer confirmation must only happen after approval and successful calendar booking.
